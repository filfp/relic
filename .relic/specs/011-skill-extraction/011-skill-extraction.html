Overview

Skills → .claude/skills/relic.<name>/SKILL.md — Claude Code's native skill directory format. Each skill is a folder: SKILL.md entrypoint + optional supporting files. Proactive skills auto-invoke via description frontmatter — no user-maintained file required. Existing .claude/commands/relic.*.md workflow commands are unchanged. File ownership boundary: Relic writes only to directories and files it created and owns (.claude/skills/relic.*/, .claude/commands/relic.*.md, .claude/settings.json). It must never write to user-maintained files (.claude/CLAUDE.md, .claude/agents.md). The boundary is ownership, not directory. Prerequisite: Spec 010-prompt-snippet-injection must be implemented first. Skills use <!-- include: relic snippet <name> --> directives for their preamble blocks.

Spec 010 extracted static text into snippets. One problem remains: procedural steps are trapped inside commands. The artifact search cascade only fires when the user invokes /relic.specify or /relic.plan. The LLM has no access to those procedures outside a relic command flow.

This spec delivers Track 2 — Skill extraction and proactive workflow integration: standalone skill directories written to .claude/skills/relic.<name>/SKILL.md — Claude Code's native skill format, which supports bundled supporting files and native auto-invocation via description frontmatter.

Principle: procedures → skills. Relic integrates into the flow, not just the commands.

Skill Archetypes

Procedural

Extracted from command templates. Execute a focused procedure (artifact search, intersection check). Referenced from prompts via <!-- use: -->. Can also be invoked directly by the user.

Proactive

Ambient monitors. Fire silently based on conversation context. Detect when a relic workflow is relevant and ask the user to confirm before activating. Never act without confirmation.

Snippet → Skill migration: The search-knowledge snippet inlines its procedure text eagerly (always in context). The search-context skill is lazy — invoked only when needed. Prompts become lighter; the search procedure can be richer. All <!-- include: relic snippet search-knowledge --> directives in templates/prompts/ must be replaced with <!-- use: relic.search-context -->.
